# Lab 07 - Estruturas Complexas

Crie:

```text
estruturas.yml
```

Ele deve executar em `localhost`.

Crie um dicionário `aplicacao` contendo:

- nome
- diretório
- porta

Crie uma lista `usuarios` com pelo menos dois usuários, cada um contendo:

- nome
- grupo
- shell

O playbook deve:

1. exibir dados da aplicação
2. exibir o primeiro usuário
3. percorrer todos os usuários com `loop`
4. usar notação de colchetes para dicionários
