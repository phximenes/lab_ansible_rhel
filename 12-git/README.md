# Lab 12 - Git aplicado à Automação

Inicialize um repositório Git neste diretório.

Crie também:

```text
.gitignore
```

Ele deve ignorar, no mínimo:

- logs
- retry files
- artefatos de execução
- `.env`
- arquivos de senha do Vault

Depois:

1. faça o primeiro commit
2. crie a branch `feature/apache`
3. faça uma alteração
4. use `git diff`
5. faça commit
6. exiba o histórico em formato gráfico
